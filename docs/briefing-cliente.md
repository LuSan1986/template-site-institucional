# Briefing de Levantamento de Requisitos — Site Institucional

Use este documento para conduzir a reunião inicial com o cliente.
Preencha as respostas durante ou após a conversa.

---

## 1. Sobre o Negócio

- Qual é o nome da empresa/marca?
- Qual é o segmento de atuação?
- Quem são os principais concorrentes?
- Qual é o diferencial da empresa em relação aos concorrentes?
- A empresa já tem identidade visual (logo, cores, tipografia)? Se sim, como receber os arquivos?

---

## 2. Objetivos do Site

- Por que você quer um site agora?
- O que o site precisa fazer pelo seu negócio? (gerar leads, apresentar portfólio, vender, informar...)
- Como você vai medir se o site foi um sucesso? (número de contatos, visitas, vendas...)

---

## 3. Público-Alvo

- Quem é o seu cliente ideal? (idade, gênero, localização, profissão, renda)
- O que esse público busca ao chegar no site?
- Qual o nível de familiaridade digital desse público?

---

## 4. Conteúdo e Páginas

- Quais páginas o site precisa ter? (Início, Sobre, Serviços, Portfólio, Blog, Contato...)
- Quem vai fornecer os textos? (cliente escreve, ou você redige?)
- O cliente tem fotos profissionais? Vai precisar de banco de imagens?
- Tem vídeos para incluir?
- Vai precisar de blog ou área de notícias?

---

## 5. Funcionalidades

- Precisa de formulário de contato? Para qual e-mail as mensagens devem chegar?
- Precisa de mapa de localização?
- Precisa de integração com WhatsApp?
- Precisa de links para redes sociais? Quais?
- Vai precisar de área administrativa para o cliente atualizar conteúdo?
- Vai vender produtos online? (e-commerce)
- Precisa de chat ao vivo?

---

## 6. Referências Visuais

- Cite de 2 a 3 sites que você gosta (não precisa ser do mesmo segmento).
- O que você gosta nesses sites? (layout, cores, animações, simplicidade...)
- Existe algum estilo que você definitivamente NÃO quer?

---

## 7. Prazo e Orçamento

- Você tem uma data de lançamento em mente?
- Existe algum evento ou campanha que o site precisa estar pronto para suportar?
- Qual é o orçamento disponível para o projeto?
- Haverá verba para manutenção mensal após o lançamento?

---

## 8. Acesso e Infraestrutura

- Você já tem domínio registrado? (ex: minhaempresa.com.br) Qual é?
- Você já tem hospedagem contratada?
- Quem será o responsável técnico pelo site após a entrega?
